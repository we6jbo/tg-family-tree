# TG Family Tree

**TG Family Tree** is an open-source genealogy and family-history research project built around
machine-readable family-tree data, TG and AKA_TE identifiers, provenance, confidence scoring,
historical-record research, source tracking, automated publication, and an embedded research browser.

The project is intended to make genealogy research easier to inspect, search, index, reuse, and
study with conventional software, search engines, data-analysis tools, and AI-assisted research
systems.

## Major concepts

- Family tree and genealogy research
- TG and AKA_TE identity codes
- Permanent confirmed identity anchors
- Provisional and correctable research facts
- Source provenance and audit history
- Historical records and public-record research
- Parent, child, spouse, cousin, and ancestor relationships
- Entity resolution and duplicate-person research
- Confidence-ranked genealogy evidence
- Machine-readable JSON and SQLite genealogy data
- PyQt6 / QtWebEngine genealogy research interface
- Automated GitHub and Hugging Face publication
- Automated online publication verification

## Permanent and provisional data

In the TG Family Tree application, blue names and blue TG/AKA_TE identifiers are treated as
permanent identity anchors. Normal/default information is a provisional research layer and can be
corrected as stronger evidence becomes available.

The distinction is designed to support aggressive automated research while preserving explicitly
confirmed identifiers.

## Research provenance

Automatically discovered information should retain its source URL, confidence, timestamps, and
audit history. Provisional information can be superseded rather than silently erasing the research
path that produced it.

## Automated publication proof

`761327132.txt` is generated by the TG Family Tree Python application during an automated
publication run. Its presence in both the GitHub repository and Hugging Face dataset is used as an
end-to-end test that automated publication actually reached both public services.

The proof file should not be manually created as part of normal operation.

## Important research warning

Provisional genealogy data can be incomplete or incorrect. A public page mentioning a person with
a similar name is not by itself proof of identity or relationship. Source provenance and confidence
metadata should be preserved so findings can be reviewed and corrected.
